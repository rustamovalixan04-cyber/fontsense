# Independent font release review

Proposed commit: `Add independent fonts and retrain the matcher`

Adds 81 licensed independent families (154 styles), checksum-pinned build assets, family/source-separated training, encoder adaptation, a rebuilt 1,943-family index and a refitted correctness gate. Keeps the assessed classifier unchanged.

Checks: 106 tests passed; 153 source files rebuilt from fresh downloads; warm-start and ONNX parity passed; development queries regenerated byte-for-byte. The final synthetic automatic-OCR audit retrieved 43/44 known fonts in the top three, named 36/36 correctly and withheld all 20 actual unknown queries. See the complete final report for limits, the encoder-only tie on the new test set and the small old-font macro F1 decline.

No font programs, generated image datasets, downloads, API keys or MLflow stores are included. The 729,216-byte safe NumPy warm-start checkpoint is necessary for reproducibility and excluded from deployment. Codex assistance is acknowledged in the documentation.
