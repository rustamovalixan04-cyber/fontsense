FontSense Windows x64
=====================

1. Extract the complete ZIP.
2. Open the FontSense folder.
3. Double-click FontSense.exe.
4. Wait for the browser to open and keep the console window open.
5. If the browser does not open, use the local URL shown in the console.
6. Keep all files in the FontSense folder together.
7. No Python installation is required.
8. Windows SmartScreen may warn because the app is unsigned.

Close the console window or press Ctrl+C to stop FontSense.

FontSense predicts broad font categories, not exact font family names.
