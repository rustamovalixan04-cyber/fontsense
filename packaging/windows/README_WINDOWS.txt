FontSense Windows x64
=====================

1. Run FontSense.exe.
2. Keep the console window open while using FontSense.
3. Your default browser should open automatically.
4. If it does not, open the local URL printed in the console.
5. Close the console window or press Ctrl+C to stop FontSense.
6. No Python installation is required.

FontSense predicts broad font categories, not exact font family names.
The executable is unsigned, so Windows SmartScreen may show a warning.
